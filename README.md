# MAXHUB — כיתות לימוד חכמות | נס מטח

אתר נחיתה סטטי בעברית (RTL) של **נס מטח** — המפיץ הבלעדי של MAXHUB למוסדות החינוך בישראל.
מיועד למנהלי בתי ספר: מציג מסכי מגע אינטראקטיביים, למידה מרחוק ושיתוף תוכן אלחוטי,
עם סרטון הדרכה מחולק לפרקים לחיצים וכפתורי יצירת קשר מוכנים לשליחה.
